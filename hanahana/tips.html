仕様・法則

設定変更後の1G目

  • リールがガックンと動く
  • 個体差や出目によっては、分かりにくいこともある

重複ボーナスの演出

  • スイカ・ベル・リプレイとの重複BIG → 必ず何かしらの特別な演出がある
  • チェリー重複ボーナス → REGもあるので、重複が確定していても特別な演出がないことがある。演出があればBIG

中段チェリー

  • チェリー重複のとき、4コマ滑って中段にチェリーが止まる位置をビタ押ししたときだけ出る（チェリー重複ボーナス確定）
  • 払い出しは1ライン分少なくなる

REG後のフェザーランプ

  • 色が付く確率は、ゲーム数に応じて段階的に上がる
  • 電源を切るとリセットされる

設定変更後1回目のBIGの
フェザーランプ

  • 白・青・黄・緑・赤が均等の確率で選ばれる

BIG後の連チャンサウンド

  • 連チャンサウンドになる権利・状態は、電源を切っても引き継がれる
  • 設定変更でリセットされる

ストップボタン
受付開始のタイミング

  • 実機で確かめた結果から導いた法則
  • 各リールには10番と21番の2か所に基準点がある（ほぼ半周間隔）
  • 3リールすべてが基準点を通過した3コマ後に、3リール同時に受付が始まる
  • 一番遅れて基準点に届くリールで、受付のタイミングが決まる
  • 例：出目 左4・中5・右10 → 一番遅いのは左（10番まで6コマ）。6＋3＝9コマ進んだ左13・中14・右19で受付開始
  • 例：右だけ11にすると、右が21番まで10コマかかる。10＋3＝13コマ進んだ左17・中18・右3で受付開始
  • 11番は基準点を通過した直後なので、どのリールでも受付が一番遅くなる位置
式
d = min((10 − S) mod 21, (21 − S) mod 21)
D = max(d左, d中, d右) + 3
X = ((S − 1 + D) mod 21) + 1

S … レバーを叩く前の中段の番号
d … S から次の基準点までのコマ数
D … 始動から受付開始までに進むコマ数（3リール共通）
X … 受付が始まった瞬間の中段の番号

だちょうとろぴさんの研究

ブログ「ひぐらしの華が咲く頃に～引き弱だちょうのハナハナ街道記～」から、リール制御・出目の研究を紹介。詳しくは各記事で。
記事中の赤7・赤BARは、このサイトのピンク7・ピンクBAR。

スベリと成立契機

同じ1確目でも成立契機が違う？

スイカ・白7・スイカのBIG確定目は、左が何コマ滑って止まったかで、単独成立・チェリー重複・スイカ重複に分かれる。出目だけでは単独かチェリー重複か見分けられず、演出でしか分からない1確目も紹介されている。

出典：だちょうとろぴさんのブログ「ハナハナ雑学(ボーナス確率の簡単な覚え方)など」対象：ハナハナシリーズ

同じ2確目でも出し方が変わる？

左のスベリコマ数によって中・右の制御が変わるので、同じ2確目でも出すための条件が変わる。小役狙いのときの代表的な2確目ごとに、出現条件をまとめた研究。

出典：だちょうとろぴさんのブログ「【再編集】2確目の条件とは？【ハナハナシリーズ】」対象：ハナハナシリーズ

BIG・REGの判別

ハサミ打ちでピンク7が
単独テンパイしないのにBIG？

ハサミ打ちでピンク7を揃えにいくとき、右でピンク7が単独テンパイするかどうかは、左が何コマ滑ったかで変わる。左の止まり方ごとに、BIG確定・REG確定になる形と、最後まで分からない形を整理した研究。

出典：だちょうとろぴさんのブログ「意外と知らない人が多い？ハサミ赤7テンパイのヒミツ」対象：ハナハナシリーズ

ボーナス図柄のテンパイで
BIG・REGが分かる形

告知されたゲームで小役が成立していないとき、ボーナス図柄のテンパイの仕方でBIG・REGが分かる形を、ハサミ打ち・右から・左最終停止などの押し順ごとに紹介。

出典：だちょうとろぴさんのブログ「マニアックハナハナ(告知プレイで分かるBIG＆REG確定目)」対象：クイーンハナハナ以降（中リールが絡む目は使えない機種もある）

チェリー

チェリー重複のハナハナ目は
押す位置で決まる？

チェリー重複のときに出る3連チェリー・ズレ目・中段チェリーを、どこを押せば出せるかとともに紹介。当たっていても、押した位置によってはハナハナ目にならない制御があることが分かる。

出典：だちょうとろぴさんのブログ「ハナハナ目特集その5【チェリー重複の形】」対象：ハナハナシリーズ

当たっていても
3連チェリーにならない？

チェリーが止まったときのスベリコマ数で種無しが分かる形や、手前で押しすぎると重複でも3連チェリーを引き込まない制御など、スベリコマ数まで見て初めて分かるチェリーの法則をまとめた研究。

出典：だちょうとろぴさんのブログ「実はまだ公に出していなかったハナハナのチェリーの秘密」対象：クイーンハナハナ以降

チェリーのフラグは1つだけ？

ハナハナのチェリーはフラグが1つで、単独か重複かはリール制御だけで出し分けられている、という解説。ほかの機種のチェリーと比べながら、変則押しで3連チェリーがガセになる形にも触れている。

出典：だちょうとろぴさんのブログ「分かると面白さ倍増？チェリーの特徴あれこれ」対象：ハナハナシリーズ（スペシャルハナハナ以前を除く）

重複したチェリーを取りこぼすと
ハナハナ目が出る？

ボーナスと重複したチェリー・スイカを取りこぼしたときは専用のスベリコマ数が選ばれ、残りのリールはハナハナ目を作る制御になる。小役→ボーナス→ハナハナ目という制御の優先順位も解説している。

出典：だちょうとろぴさんのブログ「ハナハナ雑学(ボーナス確率の簡単な覚え方)など」対象：ハナハナシリーズ

押し順・打ち方

中押しだと
チェリー重複の出目が変わる？

中押しのときのチェリー重複の制御を解説。中押しでボーナスの2確目になる形の一部が、チェリー重複のときは出ない。

出典：だちょうとろぴさんのブログ「実はまだ公に出していなかったハナハナのチェリーの秘密」対象：クイーンハナハナ以降

スライド打ちの取りこぼしは
出目で分かる？

ピンクBAR狙いのスライド打ちで、スイカやチェリーを取りこぼしたときの形を紹介。出目で取りこぼしと分かる形と、スベリコマ数を見ないと分からない形がある。

出典：だちょうとろぴさんのブログ「【華シリーズ】スライド打ちはここに注意！」対象：ハナハナシリーズ

ハナハナ目

左下BARから出るハナハナ目

小役狙いの基本、左BAR枠内から出るハナハナ目を、一直線型・小役ハズレ型などの法則ごとに整理。法則ごとにあるNGの形もまとめられている。

出典：だちょうとろぴさんのブログ「ハナハナ目特集その1【左下BARからの形】」対象：クイーンハナハナ以降

左上段にスイカが
滑ってきたときのハナハナ目

左上段までスイカが滑ってきてハズレたときの形を集めた特集。BIG確定になる形や、スベリコマ数で意味が変わる形が分かる。

出典：だちょうとろぴさんのブログ「ハナハナ目特集その2【スベリ左上段スイカハズレの形】」対象：クイーンハナハナ以降

左上段に白7が
滑ってきたときのハナハナ目

左上段まで白7が滑ってきてハズレたときのハナハナ目の特集。右の止まり方でBIG・REGが分かる形や、左のスベリコマ数が限られる2確目も紹介。

出典：だちょうとろぴさんのブログ「ハナハナ目特集その3【左上段白7スベリハズレの形】」対象：クイーンハナハナ以降

小役の並びで見るハナハナ目

スイカの小V型や、7・BAR・チェリーの一直線型など、スベリを気にせず見た目の並びで分かるハナハナ目の特集。

出典：だちょうとろぴさんのブログ「ハナハナ目特集その4【その他諸々】」対象：ハナハナシリーズ

止まっただけで
小役以上が確定する図柄

左・中・右のリールごとにある強力図柄と、その役割を紹介。後告知のときにハナハナ目に気付くための基本になる。

出典：だちょうとろぴさんのブログ「ハナハナの出目法則【強力図柄編】」対象：ハナハナシリーズ

スターハナハナで
見たいハナハナ目50

スターハナハナはボーナス後101G以降に単独後告知の割合が上がるので、ハナハナ目を知る価値が大きい。選び抜いた50の出目を、難易度付きのミッション形式で紹介。

出典：だちょうとろぴさんのブログ「スターハナハナの特性を考え、ハナハナ目をミッション形式でおさらいしてみよう」対象：スターハナハナ
