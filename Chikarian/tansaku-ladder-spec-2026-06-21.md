## 0. 範囲と現状（確認済み）
- 現行 `collect_tansaku`(0033) は**深度のみ**（浅2/中5/深10 メダル・0.5/1.2/2.5 EXP・**面で平ら**）。面/周の軸なし＝ここを置換。
- `tansaku_states` は (deck_no, **area**, depth=smallint 1/2/3, last_collect_at, is_houchi)＝**area列は既存**。`start_tansaku` は現状 **p_area≥1 の下限のみ**で上限（面別解放）ゲートなし。
- ボス進行：`profiles.cleared_stage`(0-8・恒常解放) ＋ `boss_round`/`boss_round_stage`(周回) ＋ **`boss_round_role`(0=未/1=中A済/2=中B済・0054)**。
- 結論：**スキーマ追加は基本不要**（area・boss_round_role とも既存）。`collect` のレート置換＋`start` に2ゲート追加で実装できる。

## 1. ①24段レートラダー（基準＝1周目）
### 段番号
- **step n = (面f−1)×3 + 深度d**（浅=1 / 中=2 / 深=3）。n=1..24。面f=⌈n/3⌉、深度d=((n−1) mod 3)+1。
- 面1浅=1 … 面1深=3 / 面2浅=4 … 面8深=24。**深度を別倍率にせず、24段が順に上がるだけ**（canon §3-1 意図）。

### 1周目レート（線形ランプ・仮）
| 代表段 | メダル/分・デッキ | EXP/分・カード |
|---|---|---|
| 面1浅 (n=1) | 0.33 | 0.20 |
| 面4深 (n=12) | 1.75 | 1.06 |
| 面8深 (n=24) | 3.30 | 2.00 |

- 式：`R_med(n)=0.33+(3.30−0.33)×(n−1)/23`、`R_exp(n)=0.20+(2.00−0.20)×(n−1)/23`。
- 根拠：canon-06 §3-1 仮（EXP＝実装×1/2.5・メダル＝実装×1/6）。中盤（面4深）で メダル≈1.75/分・EXP≈1.06/分＝canon の「深≈2/分・EXP深≈1.0」帯に一致。
- メダルはデッキ単位（1回収=1回）・EXPはカード単位（3枚それぞれ満額）＝現行 collect の構造を踏襲。

### 周回半減（前周最上段から継続・S+S/2+S/4…＝+2S収束）
- `inc(n)=R(n)−R(1)`、`S=R(24)−R(1)`。
- 周r：**`rate_r(n)=R(1)+S×(2−2^(2−r))+inc(n)/2^(r−1)`**。
  - r=1：`R(n)`（基準）。
  - r=2：`R(24)+inc(n)/2`（面1浅＝前周最上段 R(24) から、登り幅は半分）。
- 上限（r→∞）：`R(1)+2S = 2R(24)−R(1)` ＝ **メダル6.27/分・EXP3.80/分で頭打ち**（発散しない＝収入の安全性）。
- レートは **(面, 周, 深度)=(area, boss_round, depth) から都度算出**。**マップ保存不要**。半減比 1/2 は仮。

### 収入チェック（代表点・要シミュ）
- 1周目・面4深・1デッキ24h：メダル 1.75×1440≈**2,520/日**、EXP 1.06×1440≈**1,526/日・枚**。
- canon-04 §7 目標：探索/放置 ≈**2,000/日**（メダル）。→ 主力1デッキ面4でほぼ到達（放置デッキ分は最下段0.33/分で上乗せ）。
- EXP 1,526/日・枚 → SR上限(24,500)≈Day16・SSR上限(35,400)≈Day23 ＝ canon「Lv最大≒Day20」帯。
- ※複数放置デッキの合算・farm時間で前後する。**最終分布は Phase 4 で調整**。

## 2. ②面別解放（ボス進行相乗り・ゲート式）
- **解放ゲート ＝ `cleared_stage×3 + boss_round_role`**（＝1周目の累積撃破ノード数）。
- **探索 step n は `gate ≥ n−1` で解放**。step1（面1浅）は n−1=0 ＝ **常時開放**（放置の受け皿）。
- 検証（canon §3-2 意図と一致）：
  - ボス1-2（面1中B）撃破 → role=2 → gate=0×3+2=2 → step3（面1深 ; n−1=2）解放 ✓
  - ボス1-3（面1面ボス）撃破 → cleared_stage=1・role=0 → gate=3 → step4（面2浅 ; n−1=3）解放 ✓
  - （副次）面1中A撃破 → role=1 → gate=1 → step2（面1中）解放 ✓
- 2周目以降は cleared_stage=8 → gate≥24 ＝ **全段開放**（恒常解放のまま）。
- 実装：`start_tansaku` に上記ゲート（現状の p_area≥1 下限に加え、area↔depth から step を出して gate 判定）。シグナル `boss_round_role` は 0054 で既存。

## 3. ③戦力ゲート（本体戦闘力合計・武気フリー）
- その探索デッキの **本体戦闘力合計（3枚の本体のみ・装備項=武気は不算入）≥ しきい値(面f)**。
- 本体＝基礎×(1+(Lv−1)×rL)、rL=2.0/(Lv上限−1) ＝ Lv上限で基礎×3（★非依存）。SP本体は高い（MAX9,600/枚）が**戦力ゲートは維持**（canon §3-2・4A）。
- **しきい値(面f) は単調増加。値は Phase 4 シミュで確定**（各面の到達Day〔canon-04 §8：面1=D2 … 面8=D38〕時点の本体合計から逆算）。**構造のみ先に確定**。
- 実装：`start_tansaku` で本体合計を算出（`start_boss_battle` と同じLv式）し、しきい値未満なら拒否。武気＝装備項は計算に含めない。

## 4. 放置（最下段常時開放）
- 放置＝探索の一モード（`is_houchi=true`）。空きデッキは自動で **step1（面1浅・常時開放）** へ。回収は `collect_tansaku` 共通（3手段＝canon §3-3）。面1浅はしきい値最小（事実上ゼロ）なので放置は常に成立。
