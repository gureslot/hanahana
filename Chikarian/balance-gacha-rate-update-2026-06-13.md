# balance §1 ガチャ排出率 更新指示（2026-06-13）

> 目的: SP帯の「1枚あたり排出率」が SR/SSR より突出していた問題を是正。
> SP1枚 ≒ SR1枚とSSR1枚の中間（約0.567%）になるよう SP帯を 5% → 1.7% に下げ、
> 減少分 3.3% を N と R に折半（C案）。SR/SSR は据え置き。

## 根拠・計算
- SP1枚の目標 = (SR1枚 0.90% + SSR1枚 0.22%) ÷ 2 = **0.56%**（SR〜SSR中間）
- SP3枚なので帯合計 = 0.56 × 3 ≒ **1.7%**（実装値）。SP1枚 = 1.7 ÷ 3 = **0.567%**
- 旧SP 5% − 新SP 1.7% = 余り **3.3%** を N/R に折半（各 +1.65%）
  - N: 53.8 + 1.65 = 55.45% / R: 30 + 1.65 = 31.65%
- 合計: 55.45 + 31.65 + 9 + 1.7 + 2.2 = **100.00%** ✓
