装備項        = 込めた装備数 × 枠攻撃力

本体戦闘力 = 基礎 × (1 + (Lv−1)×rL) × (1 + 0.15×★)   rL = 2.0 / (Lv上限−1)

## 4. 実戦闘力（boss-mockup / shurenjo-mockup / report-mockup）
```
実戦闘力 = 総合戦力 × 属性三すくみ × 装備三すくみ × スキル発動補正   （デッキ＝3枚合計）
```
- 三すくみ：**有利×1.5 / 不利×0.7 / 中立×1.0**。属性 花→芯→葉→花、装備 剣→盾→杖→剣。**カード1枚ごと**に適用（balance §2-7）。
- 1面は属性なし＝属性中立。スキルは確率発動（毎戦ブレる）。**表示は発動前で固定**。
