## 2. カード戦力（戦国IXA式・構造は確定／数値は仮）

### 2-1. 戦力計算式 【構造=確定 2026-06-10／係数=仮】

装備パワーは**戦国IXAの兵士モデル＝共通プール**。鍛冶場(兵舎)で生産しメダルで支払い、倉庫に貯まる。カードは「装備」をして、その充填量(指揮兵数)の枠に共通の装備パワーを込める。**装備ランク(銀/青/紫/金)によって、充填量1枠あたりの装備パワー消費量と攻撃力が違う**（上級ほど高コスト・高攻撃力）。

```
込めた装備数 = min( 充填量 , 手持ち装備パワー ÷ ランクの枠コスト )
装備項       = 込めた装備数 × ランクの枠攻撃力
カード総合戦力 = 装備項 + 本体戦闘力
```
- 装備パワーが充分あれば「込めた装備数＝充填量」（枠フル）。足りなければ枠が埋まらず戦力が落ちる＝**装備パワー生産(メダル)が戦力に直結**（戦国IXAで兵が足りないと指揮枠が埋まらないのと同じ）。
- 装備パワーは**1種類の共通パワー**（種類別在庫ではない＝ここが戦国IXAと違う）。ランクは「同じ共通パワーをどう変換するか（コスト効率と威力）」を決める。
- **研究で解放した装備ランクは誰でも装備できる**（カード固有ではない）。

| IXA | チカリアン | 性質 | 伸ばし方 |
|---|---|---|---|
| 兵士(共通在庫) | **装備パワー**（共通プール・量） | 戦力の主資源 | 鍛冶場で生産(メダル)・倉庫に貯める |
| 兵種ランク(足軽/長槍/武士) | **装備ランク**(銀/青/紫/金) | 枠コストと攻撃力 | 研究塔のLvで段階解放(メダル) |
| 兵攻撃力 | **ランクの枠攻撃力** | 1枠の威力 | ランクで決まる |
| 指揮兵数 | **充填量** | 込められる枠数 | カードのレベルで増える(§2-4) |
| 武将攻撃力 | **本体戦闘力** | 加算項(小) | レベルUP＋★強化(§2-2) |

### 2-2. 本体戦闘力（Lv＋★で伸びる） 【仮】★要調整
```
本体戦闘力 = 基礎 × (1 + (Lv−1)×rL) × (1 + 0.15×★)
  rL = 2.0 / (Lv上限 − 1)      （Lv MAXで基礎の約3.0倍）
  ★は上限なし（+15%/★）
```
**2026-06-09 確定：全レアの本体基礎に ×0.63 を適用（§2-8の到達設計に合わせた縮小）。SP は「本体のみで戦う」ため本体基礎を R〜SR 総合の中間に再設定（560）。**

|---|---|---|---|---|
| N | 63 | 30 | 189 | 100 |
| R | 158 | 40 | 474 | 250 |

| SSR | 441 | 60 | 1,323 | 700 |

### 2-3. 装備の攻撃力＝装備ランクで決まる（2026-06-10 改定）

**旧「レア別の装備パワー攻撃力（N7/R12/SR20/SSR30）」は廃止。** 攻撃力は**カードのレアではなく、込めた装備のランク（銀/青/紫/金）で決まる**（§2-1の枠攻撃力 20/44/96/208）。どのレアのカードでも、同じランクの装備を込めれば同じ枠攻撃力。違うのは充填量（レア・Lvで差・§2-4）。

二層構造（恒常＋一時）：
- **恒常＝装備ランク（研究塔で段階解放）**：枠攻撃力の基礎を決める。銀→青→紫→金と上げるほど高威力だが枠コスト大（§2-1）。誰でも装備可。
- **一時＝スキル「装備+%」（R帯・確率発動）**：戦闘時に装備項へ+%上乗せ（skills.md）。研究で上げた恒常値に、戦闘中さらに乗る。
- **表示戦力は発動前で固定**（装備ランクは反映・スキル発動は反映しない）。実戦ではスキル発動で毎戦ブレる。

**SPは装備パワーを持たない【確定 2026-06-09】**（装備しない・本体戦闘力のみで戦う）。SPの総合戦力＝本体戦闘力のみ。

### 2-5. （廃止）適応値＝全体係数 2026-06-09
**適応値（旧「装備容量」「統率」）は廃止**。職業×装備の三すくみ（装備タイプ属性）が「カードと装備の噛み合い」を担うため、別途の全体係数 ×0.8〜1.2 は二重計上と判断。戦力式から ×適応値 を除去（§2-1）。カード戦力＝3要素（本体戦闘力／装備パワー攻撃力／充填量）。
※同型カードの数値個体差はこれで消える。個体差は固定スキルのランダム抽選で残す（**4Aで確定 2026-06-09**＝それ以外の個体差は持たせない）。

### 2-6. 到達設計と「本体3:装備7」 【確定方式 2026-06-09／係数は仮】
- 比率3:7は**終盤の目標値**。式の乗算項（充填量×装備パワー攻撃力）が支配的なので、序盤は装備依存度がさらに高い（本体がまだ育っていないため）。★で本体を伸ばすほど3:7へ近づく ＝「後半は比率が変わる」想定そのもの。
- **到達設計はスキル込み（実戦闘力）で8面に合わせる**。素の戦力だけで8面ギリだとスキルが上乗せされ速すぎるため、§2-8で全レアを×0.63に縮小済み（§2-2〜2-4のテーブルは適用後の値）。
- **到達例（×0.63後・SSR・Lv MAX・★35・三すくみ中立）**：
  - 装備項 = 充填量630 × 装備パワー攻撃力30 = 18,900
  - 本体 = 441×(1+(60-1)×2/59)×(1+0.15×35) = 約8,270
  - 素の総合 = 18,900 + 8,270 ≈ **27,170／枚** → 3枚 約81,500（表示・発動前）
  - **スキル込み実戦闘力**（§2-8前提：装備実効51・総合×1.35・三すくみ×1.10）≈ 3枚で **約18万** → **8面（12万）の1.5倍** ✓
  - このとき装備:本体 ≈ 70:30 ✓
  - ※勝敗は実戦闘力(§2-7)で判定。有利を取れば上振れ・不利なら下振れ。スキル込みで8面×1.5に収まるのが上の確認。

### 2-7. 実戦闘力（ボス戦の勝敗・損失に使う値） 【構造=確定 2026-06-09・3b】
ボス戦は総合戦力そのままではなく**実戦闘力**で判定する（3b）。
```
実戦闘力 = 総合戦力 × 属性三すくみ補正 × 装備三すくみ補正 × スキル発動補正
デッキ実戦闘力 = 3枚の実戦闘力の合計
```
- 三すくみ：**有利 ×1.5／不利 ×0.7／中立 ×1.0**（属性＝花→芯→葉→花、装備＝剣→盾→杖→剣）。
- 属性は段階解放のため**1面は属性なし＝属性三すくみ中立(1.0)**。装備三すくみは全面適用。
- **スキルは対象が4種**（本体戦闘力／装備パワー攻撃力／総合戦力／敵デバフ・§3）。**総合戦力に乗るスキルはここで ×スキル発動補正 として掛ける**（2026-06-09・旧「別掛けしない」は撤回）。バフは**対象グループ（属性/武器）に該当する味方カードに乗る**（発動元はデッキ内の任意カード・§3）。装備パワー攻撃力系は§2-3の基礎→上限を埋める形で総合戦力に内包される（これも確率発動主体なので、総合戦力の**実戦値**が毎戦ブレる。ただし**表示は発動前で固定**＝§3）。
- **戦闘ごとの一律ランダム係数は無い**（勝敗の大筋は実戦闘力で読める）。ただし**スキルは確率発動**で、発動するとその戦闘の実戦闘力が振れ、§9の損失率・報酬が連続的に上下する。§9は連続式（clamp 0.5R）なので全損へ直行せず、全損は元々 R≧2 のときだけ。

### 2-8. 到達検算＝スキル込みで8面に合わせる 【2026-06-10 装備ランク制で再検証／全て仮】

到達設計はスキル込み（実戦闘力＝表示×三すくみ×スキル発動補正）で合わせる。装備ランク制（§2-1）＋スケール×0.80＋紫装備=8面クリア基準で、**90日デッキ（SSR3枚・★17/5/5・Lv60・紫フル）が8面の106〜179%に収まる**よう調整済み。

**前提（仮レバー）**：スケール×0.80／装備ランク 紫=枠攻撃力33（紫が8面クリア基準・金はその先）／スキル仮値 総合×(N50%×1.15・R40%×1.28・SR42%×1.45)・装備+%(R40%+50%)・本体+%(N50%+60%)／目標＝最大育成のスキル込みが8面の**約1.5倍(150%)前後**。

**90日デッキ（紫フル）のビルド別 実戦闘力 vs 8面(85,700)**：
| ビルド | 実戦闘力(3枚) | 8面比 |
|---|---|---|
| 素の総合戦力（発動前） | 91,044 | 106% |
| 固定スキルのみ（空き2空） | 108,251 | 126% |
| 混成（固定総合×＋空き装備+%×2） | 149,686 | 175% |
| 本体型（固定本体+＋空き総合×2） | 133,734 | 156% |

## 9. 装備パワーの損失（戦力差で決まる・本体は無傷） 【方式=確定／係数=仮】

戦闘で消耗するのは**装備パワーの項（充填量×装備パワー攻撃力）だけ**。**本体戦闘力は無傷**。

```
戦力比 R = 敵の戦力 ÷ 自デッキの実戦闘力（§2-7）
装備パワー損失率 = clamp( 0.5 × R , 0.10 , 1.00 )
```
| 状況 | R | 装備損失率 |
|---|---|---|
| 圧勝 | 0.5（敵が半分） | 25% |
| 互角 | 1.0 | 50% |
| 競り負け | 1.4 | 70% |
| 大敗 | 2.0以上 | 100%（全損） |

- 本体が無傷なので、**総合戦力の目減り ＝ 装備比率 × 装備損失率**。本体比率が高いカードほど目減りが小さい（あなたの「本体が総合の何割かで変わる」指摘を満たす）。
- 「状況によっては全損」＝大敗(R≧2)で装備全損。連続的で、全損は最悪ケースのみ。【確定方式 2026-06-08】
- 損失率は境界ではなく**連続（直線）**。上表は代表点で、実際は clamp(0.5R) のグラデーション。
- **実戦闘力にはスキル発動補正（§2-7・§3）が入る**ため、確率発動スキルが出た戦闘は R が少し振れ、損失率・報酬がそのぶん連続的に上下する。
- 回復は時間ではなく**鍛冶場の生産（§11）**。

報告書の表（カード単位）：**装備パワー 出撃 / 損失 / 残存**を表示。本体戦闘力は別枠で「無傷」表示。
