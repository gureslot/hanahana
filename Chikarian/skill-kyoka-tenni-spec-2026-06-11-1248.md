## 0. 概要
- 「スキル強化」「スキル転移」は**カード強化合成（★強化）とは別物の新機能**。★強化と**見た目を明確に変える（誤操作防止）**。
- スキル強化＝スキルのLvを上げる（効果量↑・**発動率は固定**）。転移＝当たりスキルを別カードの空きスロットへ移す。
- 対象＝スキル（固定1＋空き2／skills §0）。SP（dragon/girl/houou）はSP専用固定スキルを持つが、特殊枠ゆえスキル錬成・転移の対象外（両機能対象外は維持）。

## 1. スキル強化＝フェザークリスタル方式 [骨子確定／数値仮]

### 共通ルール
- スキルLvを1上げる＝クリスタルを投げて**1回挑戦**。★強化（カード素材）とは**別画面・別物**。
- 強化で伸びるのは**効果量のみ**（skills §0-A・青天井／上限なし）。**発動率は固定**（上がらない）。
- **失敗してもLvは下がらない**（クリスタル消費のみ）。Lvは分数表示しない（★に倣う＝「Lv n」のみ）。

### 成功率＝クリスタルの色で固定（Lv不問）
| 色 | 成功率 |
|---|---|
| 青 | 10% |
| 赤 | 33% |
| 虹 | 100% |
アイコン作成済み（青/赤/虹の羽根結晶）。入手元＝ミッション報酬等（§5・未定）。

### 必要個数＝1挑戦で消費する数（高Lvほど増）
- **1回の挑戦＝1色をC個消費・混色不可**（混色は成功率が定義不能なため）。失敗＝C個消失・Lv据置。

**基礎個数C（カーブ・仮）**
| 現Lv→次 | 基礎C |
|---|---|
| 1→2・2→3 | 1 |
| 3→4・4→5 | 2 |
| 5→6・6→7 | 3 |
| 7→8・8→9 | 4 |
| 9→10・10→11 | 5 |
| 11→12 〜 13→14 | 7 |
| 14→15 〜 16→17 | 10 |
| 17→18 〜 19→20 | 14 |
| 20→21 〜 24→25 | 20 |
| 25→26 〜 29→30 | 28 |
| 30→31 〜 39→40 | 40 |
| 40→41 以降 | 1帯ごと ×1.4 で増加（青天井・上限なし） |

**レア倍率（基礎Cに掛ける・仮）：N×1 / R×2 / SR×4**（skills §0-A の素材コスト比 1:2:4 に整合＝高レアほど1段が重い／N優位＝発動率の地の利を残す）。SSR はskills側SSR未確定につき後。

### 代表：Lv1→目標の累計（基礎=N／色別＝個数÷成功率の期待消費）
| 到達(Lv1→) | 基礎累計 | 虹(100%) | 赤(33%) | 青(10%) |
|---|---|---|---|---|
| →5 | 6 | 6 | 約18 | 約60 |
| →10 | 25 | 25 | 約76 | 約250 |
| →20 | 123 | 123 | 約370 | 約1,230 |
R＝上記×2、SR＝×4（例：SR Lv1→10＝虹100/赤約300/青約1,000）。深Lvを青で回すと重い＝青天井のやり込みシンク。**balance §2-8 のクリア前提はスキルLv1値**＝本カーブは90日8面クリアを縛らない（クリア後/2周目の伸びしろ）。

## 2. スキル転移 [骨子確定／数値仮]
当たりスキルを持つカードを素材にし、その**スキル1つ**を対象カードの**空きスロット**へ移す。skills §0「空き2の埋め方＝後日」をこれで充足。

| 項目 | 仕様（仮） |
|---|---|
| 取り出せるスキル | 素材カードの**固定スキル・追加スキル（空き枠）のどちらからでも選べる** |
| 1回の移送 | **1回で1スキルのみ** |
| 方式 | **移動**（複製しない＝スキルは1個のまま）。コピー不可で希少性維持 |
| 移したLv | 素材で育てたLvをそのまま持ち込む |
| 行き先 | 対象カードの**空きスロット**（空き1枠）。空き枠は属性/武器不問で載る（skills §0） |
| 素材の行方 | **消滅**。1回1スキルゆえ、**選ばなかったスキルは素材と共に失われる**（＝当たりを1つ選んで救出） |
| コスト | **メダル**（通貨一元化）。重さは★強化/クリスタルと並ぶ後調整レバー |
| 失敗 | **なし**（確定移送）。希少な当たりを確率で失うのは理不尽＝クリスタル(確率)と差別化 |
| 固定スロット | **触らない**（固定スキル変更不可は維持／引き直しは不採用） |

**整合**：固定スキル変更不可を侵さない（空き枠のみ操作）／引き継ぎ書§6「素材スキルは消滅・転移は別機能」と両立（転移＝救出ルート）／所持枠の手動整理（balance §12）と噛む（当たりを救ってから処分）。
**チェイン注**：追加スキルも移せる＝移したスキルを更に別カードへ再移送できる。ただし**毎回カード1枚＋メダルを消費**＝供給で律速（無限増殖はしない）。

## 3. 画面要件（Claude Code向け）[新規2画面・★強化と明確に分離]
共通：max-width 480px・縦持ち・Shippori Mincho・深紅/漆黒/金宝飾・**実機想起語禁止（物理描写のみ）**・画像は onerror フォールバック。

### 入口（推奨・調整可）
- **★強化＝強化合成（kyoka-mockup）のまま**。**スキル強化・転移はカード詳細（deck/zukan の右詳細）から起動**（カードの「スキル」欄にボタン）。
- 理由＝両機能とも**特定カードのスキルを操作**＝カードを見ている文脈が自然／★強化の入口と物理的に離せて誤操作防止／home 6ボタン（引き継ぎ書§7・確定レイアウト）を増やさない。

### スキル強化画面
- 対象カード（絵・族名・レアバッジ大文字）＋スキル3枠（固定1＋空き2・効果は名の下に改行＝deck流用）。強化するスキルを1つ選択。
- 選択スキルの **現Lv／現効果量／次Lvの効果量／今回必要個数C**（現Lv帯×レア倍率）。
- クリスタル色の選択（青/赤/虹＋各成功率＋**所持数**）。選んだ色の C 個を消費。
- 「挑戦」→ 約1〜2秒の演出 → 成否（成功＝Lv+1・効果量更新／失敗＝C個消失・Lv据置）。
- ★強化と**配色・モチーフを変える**（例：★強化＝赤系／スキル強化＝青〜虹の結晶系）＝一目で別画面と分かる。

### スキル転移画面
- 受け取る側カード（空き枠を表示）＋素材カード選択（deck流用の一覧）。
- 素材の**全スキル（固定・追加）を一覧** → 移す1つを選択 → 空き枠を選択。
- 確認ポップアップ：「**素材カードと、選ばなかったスキルは失われます**」＋メダル消費額 → 実行で確定移送（失敗なし）。
