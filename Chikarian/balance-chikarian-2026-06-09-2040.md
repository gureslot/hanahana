## 2. カード戦力（戦国IXA式・構造は確定／数値は仮）

### 2-1. 戦力計算式 【構造=確定／係数=仮】
```
カード総合戦力 = ( 充填量 × 装備パワー攻撃力 ) + 本体戦闘力
```
戦国IXAの「部隊総攻撃力 =（兵数×兵攻＋将攻）」を移植（**統率ランク＝全体係数は廃止**。カードと装備の相性は装備タイプ属性で表現し二重計上を避ける）。

| IXA | チカリアン | 性質 | 伸ばし方 |
|---|---|---|---|
| 武将攻撃力 | **本体戦闘力** | 加算項（小さい） | レベルUP＋★強化 |
| 兵攻撃力 | **装備パワー攻撃力**（1単位） | 乗算項（支配的） | 頭打ち→スキルで伸ばす |
| 指揮兵数 | **充填量** | 乗算項の数量 | レベルで増える |

※ボス戦は攻撃側のみのため**攻撃力＝戦力で一本化**。防御力は将来の対人/防衛で拡張余地として残す。【確定 2026-06-08】

### 2-2. 本体戦闘力（Lv＋★で伸びる） 【仮】★要調整

```
本体戦闘力 = 基礎 × (1 + (Lv−1)×rL) × (1 + 0.15×★)
  rL = 2.0 / (Lv上限 − 1)      （Lv MAXで基礎の約3.0倍）
  ★は上限なし（+15%/★）
```

### 2-5. （廃止）適応値＝全体係数 2026-06-09
**適応値（旧「装備容量」「統率」）は廃止**。職業×装備の三すくみ（装備タイプ属性）が「カードと装備の噛み合い」を担うため、別途の全体係数 ×0.8〜1.2 は二重計上と判断。戦力式から ×適応値 を除去（§2-1）。カード戦力＝3要素（本体戦闘力／装備パワー攻撃力／充填量）。
※同型カードの数値個体差はこれで消える。個体差は固定スキルのランダム抽選で残す（**4Aで確定 2026-06-09**＝それ以外の個体差は持たせない）。

### 2-6. 到達設計と「本体3:装備7」 【確定方式 2026-06-09／係数は仮】
- 比率3:7は**終盤の目標値**。式の乗算項（充填量×装備パワー攻撃力）が支配的なので、序盤は装備依存度がさらに高い（本体がまだ育っていないため）。★で本体を伸ばすほど3:7へ近づく ＝「後半は比率が変わる」想定そのもの。
- **到達設計はスキル込み（実戦闘力）で8面に合わせる**。素の戦力だけで8面ギリだとスキルが上乗せされ速すぎるため、§2-8で全レアを×0.63に縮小済み（§2-2〜2-4のテーブルは適用後の値）。
- **到達例（×0.63後・SSR・Lv MAX・★35・三すくみ中立）**：
  - 装備項 = 充填量630 × 装備パワー攻撃力30 = 18,900
  - 本体 = 441×(1+(60-1)×2/59)×(1+0.15×35) = 約8,270
  - 素の総合 = 18,900 + 8,270 ≈ **27,170／枚** → 3枚 約81,500（表示・発動前）
  - **スキル込み実戦闘力**（§2-8前提：装備実効51・総合×1.35・三すくみ×1.10）≈ 3枚で **約18万** → **8面（12万）の1.5倍** ✓
  - このとき装備:本体 ≈ 70:30 ✓
  - ※勝敗は実戦闘力(§2-7)で判定。有利を取れば上振れ・不利なら下振れ。スキル込みで8面×1.5に収まるのが上の確認。

### 2-7. 実戦闘力（ボス戦の勝敗・損失に使う値） 【構造=確定 2026-06-09・3b】
ボス戦は総合戦力そのままではなく**実戦闘力**で判定する（3b）。
```
実戦闘力 = 総合戦力 × 属性三すくみ補正 × 装備三すくみ補正 × スキル発動補正
デッキ実戦闘力 = 3枚の実戦闘力の合計
```
- 三すくみ：**有利 ×1.5／不利 ×0.7／中立 ×1.0**（属性＝花→芯→葉→花、装備＝剣→盾→杖→剣）。
- 属性は段階解放のため**1面は属性なし＝属性三すくみ中立(1.0)**。装備三すくみは全面適用。
- **スキルは対象が4種**（本体戦闘力／装備パワー攻撃力／総合戦力／敵デバフ・§3）。**総合戦力に乗るスキルはここで ×スキル発動補正 として掛ける**（2026-06-09・旧「別掛けしない」は撤回）。バフは**対象グループ（属性/武器）に該当する味方カードに乗る**（発動元はデッキ内の任意カード・§3）。装備パワー攻撃力系は§2-3の基礎→上限を埋める形で総合戦力に内包される（これも確率発動主体なので、総合戦力の**実戦値**が毎戦ブレる。ただし**表示は発動前で固定**＝§3）。
- **戦闘ごとの一律ランダム係数は無い**（勝敗の大筋は実戦闘力で読める）。ただし**スキルは確率発動**で、発動するとその戦闘の実戦闘力が振れ、§9の損失率・報酬が連続的に上下する。§9は連続式（clamp 0.5R）なので全損へ直行せず、全損は元々 R≧2 のときだけ。

### 2-8. B検算＝スキル込みで8面に合わせる 【適用済み・2026-06-09／前提は仮】
到達設計はスキル込み（実戦闘力＝表示×三すくみ×スキル発動補正）で合わせる。素の戦力で12万だとスキルが上乗せされ8面が速すぎるため、**全レアの本体基礎・充填量MAXを ×0.63 に縮小（§2-2〜2-4へ適用済み）**。

**前提（レバー・要確認）**：L1 装備パワー攻撃力の実効値＝51（基礎30→上限60の途中・確率発動の期待値）／L2 総合系スキルの期待値倍率＝×1.35／L3 三すくみ＝×1.10／目標＝理論最大育成のスキル込みが8面ボスの**約1.5倍**。

| | 素の総合戦力(表示・3枚) | スキル込み実戦闘力(3枚) | 8面(12万)比 |
|---|---|---|---|
| 旧§2-6（×0.63前・充填1000・本体基礎700） | 129,375 | 285,677 | 2.38倍（超過＝不採用） |
| **現行（×0.63適用後）** | **81,506** | **179,976** | **1.50倍（目標・採用）** |

- **スケール0.63はL1〜L3と目標倍率に依存**。スキルの強さ感／目標倍率が変われば0.63も動く＝スキル数値（skills.md）確定時に再検算する。
- SP（本体のみ）は×0.63の対象外で本体基礎560（§2-2）。R〜SR総合の中間に位置。
- **日ごとの到達ペース（例：Day150で8面）は採取・報酬レート（§4/§6/§7・仮）込みの別シミュレーションで別途**。本節は終点（最大育成 vs 8面）の検算のみ。



スロット＝**固定1＋空き2（計3）**。乗算のみ。**SP（dragon/girl/houou）はスキルなし・空きスロットなし**。固定スキルはカードごとにランダム付与・変更不可。合成でスキルLv↑＝効果量↑。空き2の埋め方（スキル石/転移）は別機能で後日（今は枠のみ）。

**対象指標は4種**：①本体戦闘力 +%（§9損失軽減も兼ねる）②装備パワー攻撃力 +%（§2-3の基礎→上限・主火力）③総合戦力 ×（§2-7に ×スキル発動補正）④敵戦力 −%（デバフ）。

**効かせ方＝「対象グループに対して」**（主流）。スキルは**デッキ内の特定の属性/武器のカードを強化**する（例：花属性の味方の総合×／剣盾の味方の装備パワー+）。対象グループ＝属性(花/葉/芯)の単1種・複2種、武器(剣/盾/杖)の単1種・複2種。**自分のみ対象（自己単体強化）は特殊枠でごく一部**。敵デバフは対象＝敵。

**付与ルール**：**固定スキル(1枠)はそのカードの属性 or 武器を含むグループのバフからのみ抽選**（花カードに葉専用の固定バフは付かない）。**空きスロット(2枠)は制限なし＝自由付与**（別機能・後日）。

**発動＝確率発動が主体**（基本は毎戦ブレる）。常時(100%)はごく一部の下支えのみ＝小アュラ・非戦闘の補助系。低確率ほど効果の天井↑、**発動率×効果量を期待値で均衡**。グループが狭い(単1種)ほど高め、広い(複2種/全体)ほど低め。条件軸は**属性(花/葉/芯)と武器(剣/盾/杖)のみ**（職種は武器に統合）。**表示戦力は発動前の素の総合戦力で固定**（§2-3）。

→ 種類・効果・発動率・レア帯の一覧は **skills-chikarian.md**。数値は全て仮で、固定1＋空き2を積んだ合計（×3枚・同属性デッキでの重なり）が§2-6到達例を壊さない範囲＝数値の詰め(D)で最終調整。

## 9. 装備パワーの損失（戦力差で決まる・本体は無傷） 【方式=確定／係数=仮】

戦闘で消耗するのは**装備パワーの項（充填量×装備パワー攻撃力）だけ**。**本体戦闘力は無傷**。

```
戦力比 R = 敵の戦力 ÷ 自デッキの実戦闘力（§2-7）
装備パワー損失率 = clamp( 0.5 × R , 0.10 , 1.00 )
```
| 状況 | R | 装備損失率 |
|---|---|---|
| 圧勝 | 0.5（敵が半分） | 25% |
| 互角 | 1.0 | 50% |
| 競り負け | 1.4 | 70% |
| 大敗 | 2.0以上 | 100%（全損） |

- 本体が無傷なので、**総合戦力の目減り ＝ 装備比率 × 装備損失率**。本体比率が高いカードほど目減りが小さい（あなたの「本体が総合の何割かで変わる」指摘を満たす）。
- 「状況によっては全損」＝大敗(R≧2)で装備全損。連続的で、全損は最悪ケースのみ。【確定方式 2026-06-08】
- 損失率は境界ではなく**連続（直線）**。上表は代表点で、実際は clamp(0.5R) のグラデーション。
- **実戦闘力にはスキル発動補正（§2-7・§3）が入る**ため、確率発動スキルが出た戦闘は R が少し振れ、損失率・報酬がそのぶん連続的に上下する。
- 回復は時間ではなく**鍛冶場の生産（§11）**。

報告書の表（カード単位）：**装備パワー 出撃 / 損失 / 残存**を表示。本体戦闘力は別枠で「無傷」表示。

## 11. 鍛冶場（装備パワーの生産・回復） 【仮・新設】

役割：戦闘で損失した**装備パワーを生産・補充**する（戦国IXAの兵補充に相当）。
- **時間生産**：放置で少しずつ装備パワーが回復（鍛冶場Lvで速度UP）。仮：Lv1で装備パワー +X/分。
- **即時生産**：メダル＋装備片を消費して即補充。仮：装備片n個＋メダルで装備パワー一定量。
- 上限：各カードの「充填量×装備パワー攻撃力（満タン値）」まで。
- 修練場とは別（修練場＝§記載なし・別途／鍛冶場＝装備生産）。建物4種：修練場・鍛冶場・研究塔・倉庫。

数値は全て仮。**§9の損失量と対で調整**（1日3回戦って、鍛冶場で何分/いくらで戻るか＝戦闘テンポを決める）。
